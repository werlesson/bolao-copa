Regras de Pontuação

Entenda como subir no ranking e ganhar pontos no BolãoCopa.

info

Como pontuar?

expand_more

A pontuação é calculada automaticamente após o encerramento oficial de cada partida. Os pontos não são cumulativos para uma mesma partida (você recebe apenas a maior pontuação atingida).

star

Placar exato (+3 pts)

expand_more
BRA 2 x 0 SRB
ACERTO CRÍTICO

Você ganha 3 pontos se acertar exatamente o número de gols de ambas as seleções. É a pontuação máxima por jogo.

add_chart

Vencedor e saldo (+2 pts)

expand_more

Você ganha 2 pontos se acertar o vencedor (ou empate) e também a diferença exata de gols entre as seleções.

EXEMPLO:

Palpite: 2-1 | Resultado: 1-0

check_circle

Apenas vencedor (+1 pt)

expand_more

Você ganha 1 ponto se acertar apenas qual seleção venceu a partida ou se o jogo terminou em empate, errando o número de gols.

schedule

timer Prazos para palpites

Não perca o apito inicial! Os palpites podem ser enviados ou alterados até 30 minutos antes do horário oficial de cada partida.

lock

Após o prazo, os palpites são travados para auditoria.
